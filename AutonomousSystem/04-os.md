# Which OS

I wanted to write here about why Debian instead of FreeBSD.   

First thing is Wireguard. WG has been really stable with its implementation in Linux kernel. On FreeBSD it also does work but it is only implemented from version 13.2 I guess, so this is a matter of having something with more mature support.   

Next thing is that it is better if both PoPs have the same OS, same configs etc.
If I had one PoP with Debian and one with FreeBSD, that would mean some differences in Ansible.   

And also Ansible is important here. Debian is Ansible's really well supported environment. 

Another thing is ZFS. ZFS likes a lot of RAM which I do not have on any of the PoPs. So I would have to use UFS, but that kind of defies one of the main advantages of choosing FreeBSD.   

So I will choose Debian 13 on both PoPs, I will install it manually on the Servperso one, and I will install BIRD3 from CZ.NIC repositories, as that installation is covered on [pkg.labs.nic.cz](https://pkg.labs.nic.cz/doc/?project=bird).
